# 平板智联

Windows 11 局域网副屏工具。电脑采集选中的 Windows 显示器，MatePad 通过浏览器接收。首次连接需在电脑上批准，一次可连接一台平板。

Windows 安装版为 `Tablet-Link-<版本>-Setup-<架构>.exe`。运行安装程序并批准 Windows 管理员授权后，安装程序会使用包内的驱动安装 VDD，并尝试将新虚拟屏配置为备用副屏。已安装的 VDD 会沿用当前配置。Windows 免安装版可完整解压后打开 `Tablet-Link.exe`。 [GitHub Releases](https://github.com/zhao18kai/tablet-link/releases/latest)

鸿蒙 HAP 为未签名构建，需要使用自己的签名配置安装。 [鸿蒙构建说明](harmony/README.md)

## 在 MatePad 上试用

1. 在 Windows 电脑上按下方的[从源码运行](#从源码运行)启动程序。也可以先打包，再打开生成的 `Tablet-Link.exe`。移动免安装版时请保留整个文件夹。
2. 让电脑和平板接入同一个受信任的局域网。电脑可以连网线，平板连同一路由器的 Wi-Fi。
3. 在电脑上选中要共享的屏幕和连接平板的网卡，点击 **开始共享**。
4. 用 MatePad 扫描二维码，或在平板浏览器打开桌面端显示的完整 `http://` 链接。点击 **请求观看**，再在电脑上点击 **允许连接**。
5. 点 **请求观看**时，支持全屏的接收端会自动进入全屏。播放时默认只显示画面。仅观看时轻触画面，已启用平板触控时双指轻触，即可显示或隐藏控件和视频参数。可在平板点 **断开**，或在电脑点 **停止共享**。

默认采集上限为长边 1920 像素和 120 FPS。共享时可在电脑端「画质设置」查看采集、发送或硬编帧率，在平板悬浮窗查看接收、解码和呈现帧率。持续拖动窗口或滚动页面时，对比这些帧率可定位掉帧环节。静止画面会减少传送帧数。

接收页全屏默认 **拉伸铺满（保留四边）**，窗口模式默认 **等比完整**。宽高比不同时，拉伸铺满会改变画面比例。可通过全屏控件切换为 **等比完整（可能留边）** 或 **等比铺满（裁边）**。部分 MatePad 11.5 机型可将虚拟显示器设为 1920 × 1250，以接近平板宽高比。

## 使用扩展副屏

切换到 **扩展副屏** 时，共享屏幕会优先选已启用的 VDD 扩展屏，其次是可自动创建的副屏，再其次是其他已启用的扩展屏。选择 **共享现有屏幕** 时默认匹配主屏。

**自动创建虚拟副屏**

1. 使用 Windows 安装版完成 VDD 配置。免安装版可自行安装并启用 [Virtual Display Driver](https://github.com/VirtualDrivers/Virtual-Display-Driver/releases/tag/25.7.23)。如果 Windows 仍将虚拟屏接入桌面，在显示设置中选中一块备用的 **VDD by MTT** 虚拟屏，选择 **断开此显示器**。
2. 在平板智联选择 **扩展副屏 → 自动创建虚拟副屏**，点击 **开始共享**。平板可以照常扫码或打开链接，发出观看请求。
3. 点击电脑上的 **允许连接**后，Windows 才会把备用输出接入桌面。平板断开、电脑停止共享或应用退出时，该输出恢复为备用状态。已获准的平板短暂断网后自动重连时，程序会重新接入副屏。

如果共享中把自动副屏设为主屏，或把两块现有屏幕摆成只能通过自动副屏相连，程序会保留这块副屏并提示在 Windows 显示设置中处理，以保护现有布局。

**使用现有扩展屏**

1. 让 Windows 识别第二块显示器。仅使用笔记本和平板时，可先用上游 Virtual Driver Control 为 Windows 添加一块虚拟显示器。选择它的 **Virtual Display Driver**，安装需管理员权限。 [Virtual Display Driver 官方发布页](https://github.com/VirtualDrivers/Virtual-Display-Driver/releases/tag/25.7.23)
2. 在平板智联选择 **扩展副屏**，打开 **Windows 显示设置**，选择把桌面扩展到这块显示器。Windows 也可通过 **Win + P → 扩展**切换显示模式。 [微软多显示器说明](https://support.microsoft.com/zh-cn/windows/hardware/display-graphics/how-to-use-multiple-monitors-in-windows)
3. 在平板智联选择这块扩展屏，开始共享并配对。把 Windows 窗口拖到扩展屏，平板上会显示该窗口。

使用 **VDD by MTT** 时，勾选 **跟随平板横竖屏**，已获准的平板旋转后，Windows 会调整虚拟副屏的方向。接收页会在新方向的画面准备好之前继续显示上一方向的画面。完整画面模式可保留桌面四角。

扩展副屏默认勾选 **允许平板触控**，共享前可取消。单指点击或拖拽，双指上下滑动可滚动指下的窗口。全屏时双指轻触可显示或隐藏控件。Windows 安全提示和管理员权限窗口请在电脑端操作。

拖拽中发送帧率明显下降时，平板智联会在优先保留分辨率的前提下试用运动优先。帧率改善时继续使用该模式，停止移动后恢复细节优先。

平板智联会自动刷新屏幕列表。手动选择的扩展屏断开或退出扩展模式时，共享会停止。

### 原生高帧率

在 Windows 将要共享的扩展副屏设为横屏。可用分辨率为 1920 × 1080 至 2560 × 1600，需由显示器或虚拟显示器驱动提供。在「画质设置」选择带有 `ddagrab` 和 `h264_nvenc` 支持的 `ffmpeg.exe`，勾选「原生高帧率」。分辨率上限须覆盖副屏长边。连接方式选局域网，并关闭跟随平板横竖屏。

原生模式使用 DXGI 采集和 NVIDIA H.264 硬编。Windows 副屏达到 120 Hz 时，默认画质设置以 120 FPS 为上限。状态栏显示串流目标规格，平板悬浮窗显示实际呈现帧率。启动失败时通过同一次配对回退到普通串流。串流中断时，已配对的平板会尝试自动重连到普通模式。原生共享中的画质修改在下一次共享时生效。

平板全屏控件中的「视频缓冲」可在自动、0 ms 和 20 ms 间切换。持续移动画面，比较悬浮窗里的呈现帧率和实际缓冲时间，再选适合当前连接的设置。

已获准的平板短暂断网后，请保留接收页和电脑端共享。接收页会在 30 秒内尝试自动重连，成功后保留全屏状态。关闭接收页或主动断开后需重新请求观看。

## 开机共享和快捷连接

- 在电脑左侧栏勾选 **开机自启** 和 **开机后自动共享**，手动成功共享一次。下次登录 Windows 时，应用会用上次的显示模式、屏幕、网卡、触控和转屏设置开始共享。上次的屏幕或网卡不可用时，应用会提示重新选择。
- 平板在首次扫码并获准连接后会记住这台电脑。以后在同一局域网，从 **最近连接** 选择正在共享的电脑，校验已保存的凭证后会直接连接。更新鸿蒙接收端后，收到画面时会自动进入全屏。
- 快捷连接依赖局域网的 mDNS 服务发现。访客网络或路由器的设备隔离可能阻止发现，仍可使用二维码或完整链接。

鸿蒙 7.0 平板的专用接收端工程及真机安装步骤见[鸿蒙 App](harmony/README.md)。

### 页面打不开或连接失败

- 有多张网卡时，选连接平板所在网络的 Wi-Fi 或以太网地址。更换网络后，停止共享并刷新设备，再使用新二维码。
- 使用浏览器打开二维码中的完整链接，保留 `http://` 和 `#` 后的配对令牌。首版的接收页和连接信令使用局域网 HTTP/WebSocket，适合在受信任网络中测试。
- 如 Windows 防火墙提示，核对程序路径并仅为受信任的专用网络放行 `Tablet-Link.exe`。访客 Wi-Fi 可能隔离设备，可换用允许设备互访的网络。 [微软防火墙说明](https://support.microsoft.com/zh-cn/windows/security/firewall/risks-of-allowing-apps-through-windows-firewall)
- 平板显示等待确认时，在电脑上批准请求。如果显示已经连接但没有画面，保留两个界面的状态和 HarmonyOS、浏览器版本，便于定位。

## 从源码运行

在 Windows 上使用 Node.js 24 或更高版本。首次启动或打包时会下载 Electron 运行时。

```powershell
npm.cmd ci
npm.cmd start
```

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run test:e2e
npm.cmd run package:win
```

生成含 VDD 的安装程序时，在 x64 或 ARM64 Windows 上安装 Inno Setup 6.4 或更高版本，再执行 `npm.cmd run package:installer`。如果编译器装在自定义目录，可通过 `ISCC_PATH` 指定 `ISCC.exe` 的绝对路径。打包时会获取并校验官方驱动和安装工具，成品位于 `release/Tablet-Link-<版本>-Setup-<架构>.exe`。

端到端测试使用 Windows 的实际屏幕采集和本机另一个 Edge 进程，需有桌面会话及私有 IPv4 地址。扩展屏测试还需 Windows 已启用第二块扩展显示器。打包输出位于 `release/Tablet-Link-<版本>-win32-<架构>/`。

使用 Virtual Display Driver 时，可在源码目录运行下方命令，在扩展屏上打开一个真实的 Edge 窗口。用 MatePad 扫码获准连接后，单指拖动窗口顶部的空白标题栏。也可以把记事本等日常应用移到扩展屏，试拖窗、点按和滚动。

```powershell
node test/window-drag.mjs release/Tablet-Link-0.4.2-win32-x64/Tablet-Link.exe --tablet
```

省去 `--tablet` 时，脚本用本机另一个 Edge 进程接收视频并拖动该窗口，统计从触控事件到画面预计呈现的时间，以及窗口移动、视频采集、回传和播放的时间。改用 `--continuous` 可持续快速拖窗，比较采集、发送和接收端显示的帧率。使用同一扩展屏依次测试各版本。
